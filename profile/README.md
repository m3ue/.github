# M3U Editor Suite

Self-hosted tools for managing and watching your IPTV: live TV, VOD, series, EPG, and DVR.

| Project | What it does |
| --- | --- |
| [m3u-editor](https://github.com/m3ue/m3u-editor) | Web app for managing M3U and Xtream playlists, EPG, channel mapping, and more |
| [m3u-proxy](https://github.com/m3ue/m3u-proxy) | High-performance streaming proxy |
| [m3u-tv](https://github.com/m3ue/m3u-tv) | Flutter client for Android TV, Apple TV, mobile, and desktop |
